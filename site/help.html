Getting to know PocketOS.

From the first switch-on to fixing the odd problem.

First setup

  1. Switch PocketOS on. It shows a welcome screen with a QR code and the name of its own Wi-Fi, PocketOS-XXXX.
  2. On your phone, scan the code with the camera and join that network. The setup page opens by itself. If it doesn’t, open http://192.168.4.1.
  3. Choose your home Wi-Fi and type its password. PocketOS uses 2.4 GHz Wi-Fi, which most routers provide.
  4. PocketOS restarts on your home Wi-Fi, and your phone goes back to it too. Open the link the page shows, or scan the code on PocketOS’s Settings tile.
  5. Enter the 6-digit code from the PocketOS screen. That pairs your phone, once.
  6. Follow the guide to connect Home Assistant and pick your favourites.
PocketOS’s own Wi-Fi network is only used for this first step. Afterwards everything happens on your home Wi-Fi.

The settings website

Each PocketOS runs its own small website on your home Wi-Fi. That’s where you change everything: which devices appear, favourites, menu tiles, clock, brightness, eye colour and updates.

  • To open it: tap the Settings tile (always first on the menu) and scan the code, or open http://pocketos-xxxx.local.
  • Keep it handy: on iPhone or iPad, tap Share → Add to Home Screen.
  • Honest saving: a change only shows as saved once PocketOS confirms it. If it can’t be reached, the page says nothing was changed.

Connect Home Assistant

PocketOS controls your home through Home Assistant, the free app that links smart-home brands together. Alexa, Google Home or Apple Home on their own aren’t enough.

  1. In Home Assistant, go to Settings → People → Add person. Call it PocketOS, allow it to log in, and leave Administrator off.
  2. Log in as that user (a private browser window is easiest). Tap its name at the bottom left → Security → Long-lived access tokens → Create token. Copy it.
  3. On PocketOS’s settings website, open Smart home, paste the token, check the address and press Test and connect.
Why a separate user? Home Assistant tokens can do anything their user can. A non-admin PocketOS user keeps your own login out of it. The token is kept only on PocketOS and is never shown again.

New devices you add to Home Assistant appear on PocketOS by themselves. You can review each one first or have them appear automatically (Smart home → Add new devices automatically).

Voice

Hold BOOT, say something like “turn on the floor lamp”, and let go. PocketOS shows what it heard and Home Assistant’s reply. It uses the voice assistant set up in Home Assistant (Settings → Voice assistants), which needs speech-to-text to be set up there.

Battery

PocketOS reads its battery every few seconds and keeps a 48-hour history. Once it’s spent an hour or two off the charger, it estimates how long it has left based on how you actually use it. See it on This PocketOS on the device, or on the website’s Home page with a chart.

  • The screen turns off after 30 seconds by default. “Never” uses much more battery.
  • Away from home, PocketOS sleeps and checks every five minutes whether you’re back.
  • If the battery runs out, PocketOS says so and sleeps safely. It starts again once you plug it in.

Updates

PocketOS looks for a new version once a day. On the settings website, go to More → Updates and choose one:

  • Tell me (default): a notice on the screen and the website, then you tap Install.
  • Install overnight: installs between 2 and 5 am while charging and not in use.
  • Don’t check: never looks.

Every update is checked before it’s used. If a new version doesn’t start properly, PocketOS goes back to the previous one by itself. Updates need 30% battery or a charger. See what’s new.

Two PocketOS

Each PocketOS has its own name, address (pocketos-xxxx.local), settings and paired phones. The website always shows which one you’re changing at the top. Add each to your Home Screen separately.

Problems

The settings page won’t open

Make sure your phone is on the same home Wi-Fi as PocketOS. Some Android phones don’t support .local addresses: use the IP address from This PocketOS on the device instead.

It asks for the code again

Each phone is paired once. If someone used “Forget all phones”, or PocketOS was reset, enter the new code from its screen (press BOOT to see it).

Home Assistant won’t connect

Check the address (for example http://homeassistant.local:8123) and that Home Assistant is running. If it says the token was rejected, create a new one and paste it on the Smart home page. After a rejected token PocketOS stops trying, so Home Assistant doesn’t block it.

A device says “No response”

Home Assistant didn’t confirm the change. The device may be off at the wall or offline in Home Assistant.

New router or moving house

On the settings website, More → Change Wi-Fi network. PocketOS restarts into setup and keeps everything else. If you can’t reach the website any more, a reset is the only way.

Start again from scratch

More → Reset everything on the website, then press BOOT on PocketOS within 15 seconds to confirm. Nothing is erased without that press.

Privacy

PocketOS has no account, cloud service, advertising, analytics or tracking. Your Wi-Fi password, Home Assistant token, devices and settings are stored only on PocketOS. It talks only to your Home Assistant, and once a day to GitHub to check for updates (a plain download that sends nothing about you or your home; you can turn it off). Voice goes to your own Home Assistant. This website doesn’t use cookies or analytics; Vercel, which hosts it, sees visitors’ internet addresses like any web host.
