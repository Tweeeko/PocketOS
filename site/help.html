Set up PocketOS

Setup takes a few minutes and only needs your phone.

  1. Join PocketOS’s networkSwitch PocketOS on. Scan the code on its screen with your phone’s camera to join the network named PocketOS-XXXX.
  2. Choose your Wi-FiThe setup page opens automatically. If it doesn’t, go to 192.168.4.1. Select your home network and enter its password.
  3. Open the settings pagePocketOS restarts on your home network and your phone reconnects. Open the link shown, or scan the code on PocketOS’s Settings tile.
  4. Pair your phoneEnter the six-digit code shown on PocketOS. Each phone only needs to pair once.

PocketOS works with 2.4 GHz Wi-Fi, which most home routers provide alongside 5 GHz. Its own network is only used during setup.

Connect Home Assistant

PocketOS controls your devices through Home Assistant. Alexa, Google Home and Apple Home aren’t supported directly.

  1. Create a PocketOS userIn Home Assistant, go to Settings → People → Add person. Name it PocketOS, allow it to log in, and leave Administrator turned off.
  2. Create an access tokenSign in as that user, open its profile, then Security → Long-lived access tokens → Create token. Copy the token.
  3. ConnectOn the PocketOS settings page, open Smart home, paste the token, confirm the address and select Test and connect.

A dedicated user keeps your own account separate. The token is stored only on PocketOS and is never displayed again.

Adding devices

Add new devices in Home Assistant as usual. PocketOS finds them automatically. Choose whether they appear straight away or wait for your review in Smart home → Add new devices automatically.

The settings page

Each PocketOS hosts its own settings page on your home network.

Opening it

  • Tap the Settings tile on PocketOS and scan the code.
  • Or go to http://pocketos-xxxx.local on any device on your Wi-Fi.
  • On iPhone or iPad, choose Share → Add to Home Screen for quick access.

“Sending…” means PocketOS is waiting for your home to confirm a change. If there’s no confirmation within six seconds, it shows “No response”.

Voice

Hold BOOT, speak your request, then release. PocketOS shows what it heard and Home Assistant’s reply.

Voice uses the assistant set up in Home Assistant under Settings → Voice assistants, which needs speech-to-text configured.

Battery and power

  • Battery status appears on PocketOS under This PocketOS, and on the settings page with a 48-hour chart.
  • Time remaining is estimated after a few hours off the charger, based on your actual use.
  • Screen timeout is 30 seconds by default. Choose Never only when PocketOS stays on the charger.
  • Away mode: when you leave home, PocketOS sleeps and checks every five minutes for your return.
  • Low battery: when the battery is empty, PocketOS shuts down safely and restarts once charging.

Updates

PocketOS checks for a new version once a day. Choose how updates install under More → Updates.

SettingBehaviour
NotifyShows an alert on PocketOS and the settings page. Install with a tap. Default.
Install overnightInstalls between 2 and 5 am while charging and not in use.
OffNever checks for updates.

Updates need 30% battery or a charger. Each update is verified before it runs. If a new version fails to start, PocketOS returns to the previous one automatically. See What’s new.

More than one PocketOS

Each PocketOS has its own name, address, settings and paired phones. The settings page always shows which one you’re changing. Add each one to your Home Screen separately.

Troubleshooting

The settings page won’t open

Make sure your phone is on the same Wi-Fi as PocketOS. Some Android phones don’t support .local addresses; use the IP address shown under This PocketOS instead.

I’m asked for a pairing code again

This happens after Forget all phones or a reset. Press BOOT to show the current code on PocketOS.

Home Assistant won’t connect

Check the address, for example http://homeassistant.local:8123, and that Home Assistant is running. If the token is rejected, create a new one and paste it under Smart home. PocketOS stops retrying a rejected token so Home Assistant doesn’t block it.

A device shows “No response”

Home Assistant didn’t confirm the change. Check that the device is powered and available in Home Assistant.

I’ve changed my router or Wi-Fi password

On the settings page, choose More → Change Wi-Fi network. PocketOS restarts in setup mode and keeps your other settings. If you can no longer reach the settings page, reset PocketOS.

Resetting PocketOS

On the settings page, choose More → Reset everything, then press BOOT on PocketOS within 15 seconds to confirm. Nothing is erased without that press.

Privacy

PocketOS has no account, cloud service, advertising or analytics. Your Wi-Fi password, Home Assistant token, devices and settings are stored only on the device.

  • Home Assistant: PocketOS connects only to your own Home Assistant. Voice requests go there too.
  • Updates: once a day PocketOS downloads a small file from GitHub to check for a new version. Nothing about you or your home is sent. You can turn this off.
  • This website uses no cookies or analytics. Like any host, Vercel can see visitors’ IP addresses.
