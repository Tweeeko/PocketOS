Software recovery

For servicing only. PocketOS comes with its software installed and keeps itself up to date over Wi-Fi, so you won’t normally need this page.

Use this only if PocketOS no longer starts, or if support has asked you to reinstall its software. Reinstalling erases PocketOS’s settings, Wi-Fi details and paired phones. Afterwards, set it up again from Getting started.

Reinstall PocketOS

Connect PocketOS to a computer with a USB-C cable, then select Reinstall.

This browser isn’t supported. Use Chrome or Edge on a Windows, Mac, Linux or ChromeOS computer. A secure connection is required. Open this page using https://.

Checking for the latest version…

You’ll need

  • Your PocketOS DeviceCharged, or connected to power.
  • Chrome or Edge on a computerWindows, macOS, Linux or ChromeOS. Phones and tablets can’t reinstall over USB.
  • A USB-C data cableSome cables only carry power. If PocketOS isn’t detected, try another.

Steps

  1. Connect PocketOSPlug it into your computer with the USB-C cable.
  2. Select Reinstall PocketOSChoose the port that appears, usually “USB JTAG/serial debug unit”.
  3. Erase and installWhen prompted, choose Erase. This takes about two minutes. Keep the cable connected.
  4. Set up againDisconnect PocketOS. When the setup screen appears, follow Getting started.

Troubleshooting

PocketOS doesn’t appear in the list

Try a different USB-C cable first. If it still doesn’t appear, start PocketOS in recovery mode: switch it off by holding the Power button for 6 seconds. Then hold the Boot button, and while holding it, hold the Power button for one second. Let go of both and select Reinstall again. The screen stays dark in recovery mode.

Reinstalling stopped before finishing

Select Reinstall again. If it stops repeatedly, connect PocketOS directly to the computer rather than through a hub.

Reinstalling with another tool

Download pocketos-full.bin from the latest version and write it at address 0x0 with an ESP32-S3 flashing tool.
