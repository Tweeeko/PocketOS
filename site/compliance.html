How PocketOS meets each requirement

  • Passwords (Schedule 1, paragraph 1). PocketOS has no default or shared passwords. Each device creates its own random setup Wi-Fi password on first start, and a phone must enter a code shown on that device before it can change settings. Wrong codes are locked out.
  • Reporting security issues (paragraph 2). Anyone can report a problem privately, free of charge, through the link above. Reports are acknowledged within 7 days and the reporter is kept updated.
  • Security update period (paragraph 3). The period above is published here, on the Security page and in the box. It won’t be shortened.
