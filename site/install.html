Install

Put PocketOS on your board.

You only do this once per board. After that PocketOS updates itself over Wi-Fi.

This browser can’t install PocketOS.
Open this page in Chrome or Edge on a Windows, Mac, Linux or ChromeOS computer. iPhone, iPad and Safari can’t talk to USB devices. Open this page over https:// to install.

What you need

  • A Waveshare ESP32-S3-Touch-AMOLED-1.75C. PocketOS is made for this board only.
  • A computer with Chrome or Edge. Nothing to install on it.
  • A USB-C cable that carries data. Some charging-only cables don’t.

Steps

  1. Plug the board into the computer.
  2. Press Install PocketOS above and choose the port that appears (often called “USB JTAG/serial debug unit”).
  3. If it asks whether to erase the device, choose Erase. Installing from this page always starts PocketOS fresh, so a board you already use will need setting up again. To keep its settings, use updates instead.
  4. Wait about two minutes. Keep the page open and the cable connected.
  5. Unplug and plug it back in. PocketOS greets you and shows a code to scan with your phone. Carry on with the setup guide.
The board doesn’t show up in the list

Try another cable first. If it still doesn’t appear, put the board into download mode: hold BOOT, press and release PWR (or unplug and replug the cable), then release BOOT and press Install again. When it finishes, press PWR or replug to start PocketOS.

Installation stopped part way

Nothing is broken. The board keeps its download mode, so just press Install again. If it keeps stopping, use a different USB port (not a hub).

I’d rather download the file

The latest pocketos-full.bin is on the releases page. Flash it at address 0x0 with any ESP32 flashing tool.

Already have PocketOS running? You don’t need this page for updates. PocketOS checks for new versions by itself. Open its settings website, then More → Updates.
