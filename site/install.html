Bring your PocketOS to life.

You do this once per board, from a computer. After that it keeps itself up to date over Wi-Fi.

Plug it in, then press Install.

Use Chrome or Edge on a Windows, Mac, Linux or ChromeOS computer.

This browser can’t install PocketOS.
Open this page in Chrome or Edge on a computer. iPhone, iPad and Safari can’t talk to USB devices. Open this page over https:// to install.

Checking the latest version…

You’ll need

  • A Waveshare ESP32-S3-Touch-AMOLED-1.75C. PocketOS is made for this board.
  • A computer with Chrome or Edge. Nothing to install on it.
  • A USB-C cable that carries data. Some charge-only cables won’t work.

What happens

  1. Choose the port that appears (often “USB JTAG/serial debug unit”).
  2. If asked whether to erase, choose Erase. Installing here always starts fresh.
  3. Wait about two minutes with the cable connected.
  4. Unplug and reconnect. PocketOS shows a code to scan: carry on with the setup guide.

If something goes wrong

The board doesn’t appear in the list

Try another cable first. If it still doesn’t appear, hold BOOT, press and release PWR (or unplug and reconnect), let go of BOOT, then press Install again. Afterwards, press PWR or reconnect to start PocketOS.

Installing stopped part way

Nothing is broken: press Install again. If it keeps stopping, plug straight into the computer rather than a hub.

I’d rather use the file

The latest pocketos-full.bin is on the releases page. Write it at address 0x0 with any ESP32 flashing tool.

Already running PocketOS? You don’t need this page. It checks for new versions by itself: open its settings page, then More → Updates.
