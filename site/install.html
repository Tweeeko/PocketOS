Install PocketOS

Install PocketOS from your browser in about five minutes. You only do this once. After that, updates arrive over Wi-Fi.

Requirements

  • Waveshare ESP32-S3-Touch-AMOLED-1.75CThe board PocketOS is designed for.
  • Chrome or Edge on a computerWindows, macOS, Linux or ChromeOS. Phones and tablets can’t install over USB.
  • A USB-C data cableSome cables only carry power. If the board isn’t detected, try another.

Installation

  1. Connect the boardPlug it into your computer with the USB-C cable.
  2. Select Install PocketOSChoose the port that appears, usually “USB JTAG/serial debug unit”.
  3. Erase and installWhen prompted, choose Erase. Installation takes about two minutes. Keep the cable connected.
  4. RestartDisconnect and reconnect the board. The setup screen appears. Continue with setup.

Troubleshooting

The board doesn’t appear in the list

Try a different USB-C cable first. If it still doesn’t appear, enter download mode: hold BOOT, press and release PWR, then release BOOT and select Install again.

Installation stopped before finishing

Select Install again. If it stops repeatedly, connect the board directly to the computer rather than through a hub.

Installing manually

Download pocketos-full.bin from the latest release and write it at address 0x0 with any ESP32 flashing tool.

Already using PocketOS? You don’t need to reinstall to update. Open the settings page and go to More → Updates. Installing here erases the device’s settings.
