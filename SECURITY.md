# Security

PocketOS is created by Leeko.

## Reporting a vulnerability

Please report security problems privately using
[Report a vulnerability](https://github.com/Tweeeko/PocketOS/security/advisories/new).
Reports are acknowledged within 7 days. Please don't test against devices or homes that aren't yours.

## Supported versions

The PocketOS Device receives security updates until at least 31 December 2029. Only the latest
release is supported; devices update over Wi-Fi.

## Design

See [the Security page](https://www.pocketos.co.uk/security) for how PocketOS protects a home,
and `docs/security.md` for the technical details.
